**一句话**：让"要不要追问"和"要不要说这一维倾向较轻"用**同一条尺子**——平均倾向 `|m| ≤ 0.10`；

## 1. 完整规则（推荐 D）

设某维主测有效数字回答数 `n₀`、主测净和 `S₀`；追问后合并题集为 `n₁ = n₀ + c`、净和 `S₁`
（`c` = 该维实际计入的补充题数，`0 ≤ c ≤ 4`；跳过时 `n₁ = n₀`、`S₁ = S₀`）。

```
m   = S / (2n)                                  ← 平均倾向，范围 [-1, 1]

① 覆盖（不变）   主测每维 n₀ ≥ 9，且无"未处理"题
② 追问触发 T(n) = floor(n / 5)                 ← 与 floor(2n/10) 恒等，写法按已确认口径
                                                  |S₀| ≤ T(n₀) 且 n₀ ≥ 9 时安排该维 4 道补充题；含等号
③ 最终边界 B(n) = floor(n / 5)                 ← 与 T 同一条尺子，取消现行 −1；要求 n > 0
④ 边界判定       |S₁| ≤ B(n₁)，只在**合并后的题集上判一次**（含等号）
⑤ 状态优先级（不变）覆盖不足 NEEDS_REVIEW → 任一维 S₁ = 0 为 TIED → 任一维边界为 TENTATIVE → 否则 REFERENCE
⑥ TENTATIVE 仍给四字母，候选按现有规则展开
⑦ 跳过补充题：n₁ = n₀、S₁ = S₀；"说不好"不计入 n，中立档计入 n
```

用 `m` 说人话：**"平均倾向 ≤ 0.10 → 先多问 4 题；最终仍然 ≤ 0.10 → 说'倾向较轻，两边都能说得通'"**。
现状是"平均 ≤ 0.10 追问、但只有 ≤ 0.10 再减一点（实际 0.042–0.062，`n=9` 时为 0）才算轻"。

推论（可证明，不是经验）：**凡是被标为"倾向较轻"的维度，一定被提供过追问**。
未触发的维 `n₁ = n₀`，`B(n₀) = T(n₀) < |S₀|`，不可能是边界；触发的维则都已提供追问。
所以 T 既不比需要更窄、也不浪费任何人的题量。

## 2. 为什么推荐它：哪些有证据、哪些是取舍

### 2.1 有代码级实证的三处缺陷（可复现，非主观）

1. **跳过追问与"答完追问"会得到方向相反的标签。** 同一份主测（EI `+2`、`n₀=12`）：
   - 跳过（现夹具 `CASE-09`）→ 现状 `REFERENCE`（"明确"），候选 0；
   - 完成 4 道中立档补充题（`CASE-21`）→ 现状 `TENTATIVE`（"倾向较轻"），候选 2。
   答得更多的人拿到更含糊的结论，跳过的人拿到"明确"。
   **要说清它是什么**：「补答中立后变得更不确定」本身**不是**算法错误，也不是需要修掉的缺陷 ——
   它是旧边界口径（`B = T − 1`）的直接后果，属于**产品政策取舍**：跳过一次追问之后，
   该维的最终 `S` 没变，但"算不算轻"的判据却因为题量不同而落在两侧。
   本次决定（D）让"跳过与否"不再改变"倾向是否算轻"，而不是在修一个错误。
2. **信息最少处反而最确定。** `n=9` 是覆盖下限，现状 `B(9)=0`：只要不是完全平分就判 `REFERENCE`
   （`CASE-13`：`n=9, |S|=1` 实测 `REFERENCE`）。`|S|=1` 与 `|S|=0` 之间只隔一个档位，
   却从"平分"直接跳到"明确"，中间没有"较轻"。D 下 `B(9)=1`，该格变 `TENTATIVE`。
3. **`n=0` 的定义漏洞。** `|0| ≤ B(0) = 0` 成立，于是"没有任何数字回答"的维度当前也带
   `boundary=true`（现夹具 `CASE-19` 钉住了这个事实）。今天不可达（覆盖不足先回退
   `NEEDS_REVIEW`），但任何直接读维度标记的消费方都会踩。D 显式要求 `n > 0`。

### 2.2 纯粹的产品取舍（**没有**实证支持，需你拍板）

- **`0.10` 这个数本身没有任何信度/效度/常模证据支持**，选它只有两个理由：与现网触发阈值一致
  （不制造第二套口径），且**没有超过**原开发方案的 `0.20`（不会比设计意图更保守）。
- 是否接受"跳过追问 ⇒ 只要不是完全平分，该维就显示'倾向较轻'"。
- 是否接受维度级"倾向较轻"标记出现得更多一点（每档只多一格，见 §3）。
- 需要明确写下的边界：**D 不比现状更准**，它只是把两处不一致的地方改一致、并把边界挪到与触发同一口径；
  `TENTATIVE/REFERENCE` 的真实占比、以及任何"阈值取多少才对"的问题，在拿到真实答卷分布前无法回答。

### 2.3 我考虑并放弃的另一档（供你对比）

**D′：把触发放宽到 `0.15`（`T = floor(3n/10)`）、边界 `0.10`。** 好处是`|S₀|` 刚过现触发线的维度
（`n=12` 时 `|S₀|=3`）也会被追问；代价是每多命中一维就多 4 道题（最多 +16 题），
而我们**没有任何证据**说明这 4 题会让结论更可靠。在"自我探索参考"的定位下，
我选择不主动拉长测试（D）。

## 4. 跳过与完成补充题的影响

- **完成**：`n` 增加（每维最多 +4）、`S` 累加；最终按合并题集与新口径判一次。
  补充题确实能把结论推过线：`CASE-14` 主测 `EI=+1`（`|S₁|=1`，本该"轻"）→ 完成 4 题后 `n=16, |S|=5`，
  `m=0.156 > 0.10` → `REFERENCE`，"问完就明确了"。
- **跳过**：`n`、`S` 不变。因为该维是**被触发**的（`|S₀| ≤ T(n₀)`），而 `B(n₀) = T(n₀)`，
  所以跳过后的状态必然是 **`TENTATIVE`（非平分）或 `TIED`（平分）**，不会再出现现状那种
  "跳过 → `REFERENCE` 明确"的落差。跳过是用户的知情选择，结果按"信息到此为止"如实展示。
- 覆盖不足/未作答仍优先 `NEEDS_REVIEW`，不进入这套判定。
