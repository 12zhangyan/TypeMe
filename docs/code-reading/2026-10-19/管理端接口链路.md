# 管理端接口链路 代码地图

> 日期：2026-10-19 ｜ 基线：main@78e5315 ｜ 入口选择依据：backlog A71 剩余未测模块 `frontend/src/api/v3Admin.ts`、`frontend/src/api/adminMembers.ts`
> 范围与未展开边界：前端 API 模块 → 页面/组合式函数 → 后端 `/api/v3/admin/**` 控制器与服务；未展开 `PlatformQueryService` 内部（成员测评/报告复用普通用户查询）与 AI 设置加密细节

## 概览

管理端分两块：AI 设置页 `AdminView` 走 `v3Admin.ts`，成员与邀请页 `AdminMembersView` 走 `adminMembers.ts`。两者都经 `v3Request`（`frontend/src/api/v3.ts:619`）发请求，后端由 `AdminController` 与 `AdminAccessController` 承接，两个类都整类 `@PreAuthorize("hasRole('ADMIN')")`（`backend/src/main/java/com/typeme/account/controller/AdminController.java:35`、`backend/src/main/java/com/typeme/account/controller/AdminAccessController.java:19`），非管理员得到 403。“是不是管理员”没有独立接口，由 `useAdminProbe` 调 `GET /admin/ai-settings`，200 即是、403 即否（`frontend/src/composables/useAdminProbe.ts:40-60`）。

## 状态与副作用

- 只有 PUT/POST 带 CSRF；GET 不取 token（`frontend/src/api/v3.ts:435`）。非 2xx 统一抛 `V3ApiError`，`CSRF_INVALID` 时非 GET 请求清 token 后重试一次（`frontend/src/api/v3.ts:537-559`）。
- 成员列表与计数都排除 `DELETED` 用户（`backend/src/main/java/com/typeme/account/repository/UserRepository.java:143-153`），分页口径一致；`size` 服务端裁剪到上限，`page` 裁到 0–100000（`backend/src/main/java/com/typeme/account/service/AdminUserService.java:54-67`）。
- 成员视图的 `reportCount` 查询失败时为 `null`（未知），不是 0（`backend/src/main/java/com/typeme/account/service/AdminUserService.java:137-145`）；`lastSeenAt` 取会话表最大值，无会话时为 `null`。
- 邀请状态由 `used_at` → `revoked_at` → 过期时间依次判定（`backend/src/main/java/com/typeme/account/service/InvitationService.java:69`）。撤销是条件更新：未使用的重复撤销静默成功；已使用的返回 409，提示“请刷新列表查看使用状态”（`backend/src/main/java/com/typeme/account/service/InvitationService.java:76-83`）。
- 邀请有效期必须晚于当前时间且不超过一年，前后端各校验一次（`backend/src/main/java/com/typeme/account/service/InvitationService.java:30-31`、`frontend/src/views/AdminMembersView.vue:85`）。
- 页面所有写操作经 `action()` 以 `busy` 串行；切换成员时先清空 `selected` 与 `detail` 再并行取测评与报告（`frontend/src/views/AdminMembersView.vue:61-72`）。403 或会话失效时 `fail()` 清空列表、选中成员和刚生成的邀请码（`frontend/src/views/AdminMembersView.vue:50-54`）。
