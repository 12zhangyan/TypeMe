### IM-1 的守卫有一个**被削弱的性质**（重要）

`pretest` / `prebuild` 会**先跑生成器**，所以走 `npm test` / `npm run build` 时前端副本总被自动修好，**一致性用例几乎变成恒真**。只有**直接** `npx vitest run`（跳过 prebuild）或跑 `--check` 才会红。

另：`consistency.spec.ts` 第 1 个用例会**写仓库文件**（有副作用）。
