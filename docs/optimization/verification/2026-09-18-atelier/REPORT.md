# 自我探索画册：页面与生图素材交付

日期：2026-09-18。

## 本轮改动

- 首页新增场景主视觉、双列测评封面、可选择的 16 型人物图鉴、阅读配图和三步说明；手机采用单列布局。
- 测评目录复用封面，登录/注册/找回页接入同系列场景；报告依据已有类型显示装饰人物，平分报告不随意指定人物。
- 页面内置本地 SVG 插画。新增素材按约定文件名加入 `frontend/src/assets/illustrations/` 后重新构建即可替换，文件缺失和加载失败均回退，不请求外部图床。
- 交付 5 张场景与 16 张角色的独立完整提示词，含官方特点来源、原创造型、统一画风、尺寸、透明背景、命名与生成顺序。
- 本轮不改计分、题面、认证、管理员权限或数据库。
