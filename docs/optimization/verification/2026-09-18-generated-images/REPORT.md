# 用户生成图片验收与接入

日期：2026-09-18。用户授权验收桌面 `图片` 目录，合格后接入网站。

## 结论

21 张齐全，均接入：5 张场景和 16 张人物。风格偏细腻手绘，较最初 4.5 头身卡通方案更写实，但低饱和森林绿、奶油色、陶土配色和生活场景统一，适合当前版式。缩略总览逐张检查，另放大检查了人物细节及网页输出，未见影响网页使用的明显水印、多余肢体或主体裁断。角色服饰、动作仅为原创插画设定。

- 两张测评封面：1774×887、2:1；其余源图：1122×1402、约 4:5。
- 16 张人物全部有真实 alpha 通道；完全透明像素约占 45%–72%，并非棋盘格假透明。
- 人物头像与道具丰富，原图安全边距并非严格一致，网页以 `contain` 保留全图；当前三个宽度的实际展示可接受。无需重新生成。
- 场景按容器裁切，人物不裁切。5 张场景用于首页主图、两张测评封面、阅读区和账号页；人物用于图鉴与已有类型的报告，平分报告继续不指定人物。

## 网页处理

源图总计 34,458,257 字节，网页版本共 2,622,284 字节，减少约 92.4%。人物等比例缩到 640×800，场景限制在 1440×1200 内。Pillow WebP quality=88、method=6；保留透明背景，移除 EXIF/ICC 等源文件元信息。没有覆盖桌面原图，也没有上传第三方。

`asset-manifest.json` 记录每张图的原文件名、SHA-256、网页文件名、尺寸和大小；`source-inventory.json` 记录原图格式与透明度。交付后重新校验 21 个源文件哈希均未改变，21 个构建资源与素材目录中的 WebP 字节一致。素材命名为 `type-xxxx.webp` 及既有 5 个场景名，通过已有 Vite 素材映射接入，无新增依赖或业务逻辑变更。

- 前端 `npm.cmd run build`：通过（包含 vue-tsc 类型检查）。最终构建在全部图片转换完成后执行，包含完整 21 张图。
- `npm.cmd test -- src/components/personalityGallery.spec.ts src/components/platformIntro.spec.ts`：2 个文件、5 项测试通过。

- `TYPEME_BROWSER_EVIDENCE=本目录/flows`，`python scripts/browser-verify-visual.py`：105 项流程检查通过。
- 浏览器宽度：320、390、1440。查看了主图、图鉴、目录、登录、报告及桌面整页截图。
