# 前端视觉重构验收 · 2026-09-18

本轮按用户选定的「明亮简洁：暖白、森林绿，阅读与生活方式网站」落地。只调整前端界面、少量展示文案和验收脚本；沿用当前多量表接口、计分与版本绑定。

## 本轮改动

- 首页重排为双栏介绍、测评选择、三个简短使用原则；本地 SVG 区分四维与五维测评。
- 首页与选测评页共用 InstrumentCard，题数、补充题上限、预计用时来自目录。
- 统一暖白、森林绿、清晰无衬线字体、细边框、轻阴影；登录、注册与恢复表单使用居中窄栏。
- 答题按钮采用明确选中态；大五题目清单默认收起、题号点击区至少 44px，去掉题卡里的内部维度字母与提交说明里的版本号。
- 大五报告按五个方面分区，桌面双栏、手机单栏；十六型保留不确定性提示，手机报告目录默认收起并支持键盘展开。
- 修正首页页内跳转，避免与 hash 路由冲突，跳转后将键盘焦点移交给选择区。
