# 多量表与易读性续作：实施和验收

日期：2026-09-18。承接 `docs/handoffs/2026-09-18/multiscale-platform-handoff.md`，在已有大量未提交改动上继续实现；没有提交、推送或部署。本文件区分本轮新增工作和移交前已有的平台能力。

## 本轮实际改动

1. **首页先选测评**：新增 `PlatformIntro.vue`，从公开目录读取两种量表及真实题数、时间和入口。加载、空目录、失败重试都有显示。原十六型教学和报告示例保留为折叠内容，有十六型未完成草稿时展开；通用的未完成测评入口指向选择页。全站标题与页脚改为多量表口径。
2. **报告先说人话**：Jung 报告构造器实际消费 v2 已有的 `readableSummary` / `readableFirstSteps`；保留轻微倾向提示，平分不产生完整类型。类型八段说明和推导过程默认收起；过程内仍保留来源与限制。大五先显示生活解释和一个观察动作，分数、例子与依据可展开。
3. **大五量程修正**：此前错误地把反向题补偿常量当作量程中点。按每道题的正反向键计算可达端点，五维均为 10–50，中点 30。极端作答和报告回归测试验证端点。原始分算法没变，报告体 `schemaVersion=2` 标识本轮修正；不重算持久化旧报告。旧快照范围异常时显示提示并隐藏位置条。维度解读明确写“高”或“低”，不再出现“高/低”；接近中间也不再直接解释成“灵活”。
4. **AI 简短解释贯通**：提示词 `typeme-ai-prompt-v3` → 范围 `typeme-ai-scope-v3` → 输入投影 → `analysis-readable-v2` → 服务端验证 → mock → 前端解析和展示。Jung 与大五都支持；大五类型保持 null。正文以 250–450 汉字为编辑目标，没有凑字数最低线。
5. **版本和同意范围**：新任务默认 v3；管理员显式设置旧版时保留旧版。创建时严格校验所确认范围，配置在用户确认后发生变化则拒绝并要求重新确认。任务执行使用任务绑定的提示词，避免排队期间切换设置造成输入／系统提示词错版。旧 schema 1 分析、v1/v2 提示词仍保留可读。
6. **报告入口和竞态**：旧 `/reports/:id` 收藏链接可分流到大五；大五监听报告参数变化，晚到响应不覆盖新报告。Jung store 同样拒绝过期加载响应；清空页面状态后，旧请求不能把内容重新填回来。

移交前已有的目录、两种作答页、服务端计分策略、包版本绑定、报告外壳、历史列表和账户功能继续保留；本轮不是重做这些模块。

## AI 契约与例子

实际外发：量表名称、状态、参考类型（可为空）、四或五个维度必要分数及含义、对应维度摘要证据、主题、用户自填备注和输出 schema。账号标识、报告编号、完整答卷、题库、完整历史和推导过程不进入 v3 payload。

本轮采用**维度摘要证据**，没有实现逐题语义证据库。提示词明确禁止据此声称用户在某一道题做了某个选择，也禁止把假设场景写成用户真实经历。证据 ID 校验只能证明引用来自当前报告，不能机械证明句子的心理学含义正确。

下面是用于理解结构的合成例子，不是真实用户或真实 AI 输出：

```json
{
  "schemaVersion": "analysis-readable-v2",
  "referenceType": null,
  "summary": "这次回答中，交流与独处两边差别不大，可以先保留判断。",
  "observations": [{
    "plainText": "这次结果还不足以说明你通常更偏向哪一边。",
    "example": "例如，可以回想一次聊天：结束后，你更想继续交流，还是先安静一会儿？",
    "evidenceIds": ["EI:summary"]
  }],
  "suggestedAction": {
    "what": "记下一次聊天后的感受。",
    "when": "下次聊天结束后。",
    "observe": "看自己更想继续交流，还是先独处。",
    "evidenceIds": ["EI:summary"]
  },
  "limitations": ["一次问卷不能概括所有场合；接近中间也不等于能力或性格评价。"]
}
```

观察项最多两项；行动为一个对象或 null。每条观察和非空行动必须引用白名单证据，不允许额外字段、残缺行动、无效类型或编造引用。没有依据时可返回空观察和 null 行动。旧格式不套用这些新字段规则。

## 仍需区分的未完成项

- 没有修改现有数据库、执行新迁移、启动真实后端或调用付费／真实模型。H2是一次性内存测试库；已有数据库里的显式旧prompt配置不会被本轮改掉。部署启用新版前需要检查对应环境的有效设置。
- 0.20与0.10的阈值业务选择仍未决定，本轮没有修改阈值。计算回归不证明该阈值已经有心理测量学依据。
- v2题面仍是待审校稿。本轮消费已有新内容，没有覆盖旧题库，也没有把4道修订题扩写成“全部题目已完成真人理解验证”。真人试读、中文信效度、重测与常模研究仍待做。
- 没有验证真实模型的语言质量、拒答／重试分布和成本。白名单和格式测试不等于模型不会作过度解释。
- 后端已有通用目录/策略层，存储与答案仍保留部分Jung历史类型适配；没有声称完成全部目录搬迁或完全消除历史耦合。
- 浏览器本轮没有覆盖真实双设备409、真实删除、完整补充题、200%缩放或完整无障碍合规；原有相关单测／H2测试不能替代这些真实场景。
