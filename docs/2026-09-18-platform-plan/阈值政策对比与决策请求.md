# 触发阈值政策对比与决策请求

日期：2026-09-18。状态：**待用户决定**。本轮不擅自选定数值，v2 与 v1 保持同一政策。

## 1. 两个规格分别是什么

计分口径（`docs/2026-09-16/implementation/_contracts/01-新测契约-v1.md` 与
`backend/.../JungScorer.java` 一致）：

```text
单题贡献 c = direction × (rating − 3)          rating ∈ 1..5，direction = ±1
S = Σc（整数）
n = 有效数字回答数（rating = 3 计入，unknown 与未作答都不计入）
m = S / (2n)
```

两处规格对"这一维够不够明确"给出的界不同：

| 规格出处 | 表达式 | 换算成 m | 语义 |
|---|---|---|---|
| 产品方案 / 开发方案 | `5×\|S\| ≤ 2n`，即 `\|S\| ≤ floor(0.4n)` | `\|m\| ≤ 0.20` | 更保守：更多答卷被判为"只是略偏" |
| 冻结契约 / v1 与 v2 实现 | `\|S\| ≤ floor(0.2n)` | `\|m\| ≤ 0.10` | 更激进：更多答卷被判为"方向明确" |

两者相差一倍。审计记录（`计分审计与验证记录.md` §4）已确认这不是浮点误差，
而是规格在演进中发生了实质变化，而当时的说明把它描述成了"整数化等价式"。

## 2. 实际影响（同一份答卷会得到不同结论）

取 JP 维、其他三维方向明确、跳过补充题，只看 JP 的 `n` 与 `S`：

| n | S | m | `floor(0.4n)` 触发？ | `floor(0.2n)` 触发？ | 两种政策下的总状态 |
|---:|---:|---:|---|---|---|
| 12 | 1 | 0.042 | 是 | 是 | 都是 `TENTATIVE` |
| 12 | 2 | 0.083 | 是 | 是 | 都是 `TENTATIVE` |
| 12 | 3 | 0.125 | 是 | **否** | `TENTATIVE` vs `REFERENCE` |
| 12 | 4 | 0.167 | 是 | **否** | `TENTATIVE` vs `REFERENCE` |
| 9 | 1 | 0.056 | 是 | 是 | 都是 `TENTATIVE` |
| 9 | 2 | 0.111 | 是 | **否** | `TENTATIVE` vs `REFERENCE` |

分界点：当 `n = 9` 时 `floor(0.2×9) = 1`，所以 `B(9) = max(0, 1−1) = 0`，
**非零方向在该维永远不会被标记为"只是略偏"**——该维只能是平分或"方向明确"。
这是规则效果，不是关于用户分布的经验结论。

`TENTATIVE` 与 `REFERENCE` 对用户是两句不同的话：

- `REFERENCE`：四维方向都明确，给出四字母 + 完整解读。
- `TENTATIVE`：至少一维只是略偏，页面写"本次更接近 XXXX"并明确提示另一侧也值得读。

因此这个选择直接决定"有多大比例的用户会被告知自己的结果不那么确定"。

## 3. 三个候选方案

| 方案 | 触发阈值 | 优点 | 代价 |
|---|---|---|---|
| A：保持现状 | `floor(0.2n)` | 与 v1 一致，历史报告无需区分；`REFERENCE` 更多，页面更"有结果" | `n=9` 时该维不可能出现"略偏"，与 `boundary` 想表达的"倾向较轻"语义相反；可能让边界附近的人拿到过度确定的表述 |
| B：回到原产品区间 | `floor(0.4n)` | 与产品/开发方案一致；"略偏"能真正出现在小 `n` 情形 | 与 v1 结论不一致，需要新 scoringVersion 并说明"同一份答卷为何换版本后更保守"；`TENTATIVE` 明显增多 |
| C：分层处理 | 触发澄清用 `floor(0.4n)`，最终解释用 `floor(0.2n)` | 把"要不要追问"和"结论有多确定"分开定义，两个目标各自有合适界 | 规格最复杂，需要同时解释两条界；实现与文案都要改，验证成本最高 |

## 4. 建议与理由

建议 **C**，但必须先写 ADR 并做独立样例评审再改；如果本轮必须快速收敛，则**保持 A**。

理由：

1. `T(n)` 的原始用途是"这一维证据是否足够，要不要追加补充题"，`B(n)` 的用途是
   "最终解释的语气"。让一个数同时承担两个目标，正是当前矛盾的来源。
2. 无论选哪个值，都**没有实证依据**说它更"准确"。本轮没有真人数据，
   无法用"哪个阈值预测得更准"来选。可行做法是先固定政策、收集真实答卷分布后再评估。
3. 不该为了"出更多确定类型"而调低标准（即选 A 而不是因为 A 更激进才选 A）。
