# 给实施 AI 的提示词

日期：2026-09-23。用途：让有仓库访问能力的编程 AI 按现有业务实现前端优化，包含用户明确要求的**文案减重**。本文件本身没有启动其他 AI，也不授权多位 AI 同时改同一工作区。

建议直接复制第一段“整套实施总提示词”。需要小步交接时，复制“共同约束”加对应阶段。独立审查提示词可给另一位 AI 做评审。

## 1. 整套实施总提示词（直接复制）

```text
请在当前 TypeMe 仓库直接实施前端优化，不要只给建议或重新写一份方案。

先读：
1. 仓库 AGENTS.md 和 README.md 顶部；以当前双量表实现为准。
2. docs/2026-09-23-frontend-plan/01-竞品调研与现状诊断.md
3. docs/2026-09-23-frontend-plan/02-前端优化方案.md
4. docs/2026-09-23-frontend-plan/03-文案精简与逐页改写.md
5. docs/2026-09-23-frontend-plan/05-验收标准与交付模板.md
6. 改动涉及的现有源码、契约、测试；报告涉及 TypeMe-分析建议方法论-v2.md。

目标：保留暖白、森林绿、原创插画和中文手记风格，让用户更早看见两项测评、顺畅答题、快速读懂报告。现有页面解释太多，必须真正删掉空泛、重复和内部实现说明，不是把所有长文都放进折叠区，也不是换一批更华丽的宣传话。

执行方式：
- 先 git status --short 与相关 diff，记录用户已有工作，包括未跟踪文件。
- 读当前代码后用一段话说明本批方案、文件范围和验证方式，随后直接实施普通前端编辑。
- 按阶段 0→1→2→3→4→5→6 小步执行。每阶段完成其验证，失败先定位；不要每完成一页就请求批准。
- 先改错误文案和删除冗余，再调布局，再改字号与样式；不要因为删了文字而添加更多装饰卡片填空。
- 优先复用现有组件和设计变量，不换技术栈、不新增依赖、不重写整个 CSS 或状态管理。
- 保存每阶段的实际 diff、截图与文案前后对照。上下文不足时留下可接续记录，明确哪些未完成，不冒称全部完成。

最优先解决：
1. 首页第一项测评标题当前在 390px 合成基线约 Y=1625px。提前呈现“双测评名称+区别”，减小 Hero 与卡片装饰占高。
2. 十六型报告概览在同基线约高 1263px。去掉重复类型身份/教学说明、移动大插画，保留真实结果和不确定性。
3. 页面文案按“删/缩/按需/必留/纠错”处理，参考文案文件里的 28 项清单。首批默认可见说明性字符目标减少约 30%–50%，但不能为凑指标截断固定报告。
4. 账号页“单份报告删除还没做好，只能注销账号”与已有删除入口冲突，核对当前源码后修正。登录文案不能作未经权限事实支持的绝对隐私承诺。

业务边界：
- 当前有登录版十六型与大五两条主流程，注册需要邀请码，旧本地 IPIP/OEJTS 保留兼容。
- 十六型 48 道主测、最多 16 道补充；大五 50 题、没有补充题、没有类型码和总分。题数和时长在页面读取真实目录字段。
- 未答、说不好和中间档不同；不改题目极性、评分锚点、计分阈值，不补答案。
- 保留 REFERENCE/TENTATIVE/TIED/NEEDS_REVIEW 的区别；平分不强出唯一类型，信息不足不产出有效报告。
- 草稿 revision/409、归属校验、CSRF、会话、幂等提交保持；不能让 UI 优化覆盖未保存或另一设备的答案。
- 固定报告和旧快照不重算；候选 cost 非概率；类型推导非额外测量；分享/图片/alt 与固定模型一致。
- 普通页面包装文案可删改；题干、内容包结论和旧报告内容涉及版本，不可随视觉改动静默改写。
- AI 可选，保留数据发送确认、额度和真实任务状态。没有真实调用授权，使用 mock，不外发个人数据。
- 数据库默认只读。不开后端连接现有库，不跑会注册/建草稿/提交/删除的真实接口验收；先建立完整 API mock 或明确隔离环境。
- 不提交、不推送、不部署，不删除或覆盖用户已有工作，不泄露任何凭据。

验收：
- 320×720、390×844、1440×900 的受影响页面用真实浏览器检查，补充键盘操作和 200% 缩放。
- 既验证布局，也验证保存失败、冲突、会话失效、两类报告特殊状态，不只截图正常首页。
- 实际运行风险相称的 typecheck、相关测试与 build，遵守项目生成脚本的副作用规则。不要把旧测试数量当成本次成绩。
- 不为机械匹配旧文案而保留废话。可更新纯展示文案断言，但数据、状态、授权、安全断言必须保留或加强。
- 最终报告：改动文件、解决的问题、文案删改前后、实际命令与退出码、三档截图、未覆盖风险。

请现在开始读取和实施；阶段细节参见本目录 04-给实施AI的提示词.md 的阶段 0–6。
```
