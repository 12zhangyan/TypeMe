# 文案精简与逐页改写

日期：2026-09-23。用户要求：**“好多废话可以精简一下。不用什么话都和用户解释。”**本文件把它落实为删除规则、具体改写和验收；不是另做一份品牌文案。

## 1. 最终想要的样子

页面应让人直接选、答、看。大多数时候，标题、标签、控件状态和按钮就足以说明怎么用。不要把开发者对每一种误解的担心全部写在页面上。

**默认动作是删，不是搬进折叠框。**确实能帮助用户作决定的细节才保留一个可达入口。正常状态不需要教育用户，异常状态再具体解释。

## 2. 四种处理方式

| 处理 | 适用文字 | 例子 |
|---|---|---|
| 直接删除 | 空泛情绪铺垫、反复鼓励、显而易见的操作说明、重复边界 | “每个人都是一整个世界”“从好奇到一点点理解”；按钮已有“下一题”后再说“选完点下一题” |
| 缩成一句 | 当前任务确实需要的说明、登录价值、卡片差别 | “登录后可保存进度和报告。” |
| 按需查看 | 计分口径、方法来源、完整解释、进阶理论、报错诊断 | “查看判断依据”“方法与隐私” |
| 当场保留 | 当前结果不确定、未保存、覆盖冲突、AI 数据发送、不可逆后果 | “有 3 题未保存”“部分维度两侧得分相同” |

同一句话无需既留短版、再留长版、再加 tooltip、页脚再复述。按需查看也不是收容所有被删文字的地方。

## 3. 字数与密度预算

这是**改版目标**，不是当前页面已达标的统计。统计“界面说明文字”，不把题干、选项、数据标签、固定报告结论强行压进同一预算。

| 位置 | 默认呈现目标 |
|---|---|
| 首页 Hero | 一个标题 8–16 字；最多一句副标题约 20–36 字；一个主按钮 |
| 测评卡 | 名称、一个差异句约 12–24 字、题数/时长、动作；不再附多段说明 |
| 登录页 | 标题 + 可选的一句价值说明；不要大段隐私/服务器解释 |
| 普通表单字段 | 默认只用 label；有非显然要求时一条短提示；错误时具体提示 |
| 答题页 | 题目和选项为主；通用答题引导最多一句，不随题反复堆叠 |
| 报告概览 | 一个身份/结果标题、一条必要状态说明、现有结果摘要 |
| 普通错误 | 一句原因 + 一个主要动作；通常控制在 15–40 字，确需说明损失范围时可增加 |
| 列表空态 | 一句事实 + 一个下一步 |
| 危险确认 | 操作对象 + 实际后果 + 明确按钮；不为了字数省略不可恢复或范围 |
| 页脚 | 一条简短用途说明 + 方法/隐私/必要署名入口 |

首批以首页、登录、答题外围、报告外围、账号说明为样本，争取将**默认可见的说明性字符总量降低约 30%–50%**。这是设计目标而非必须凑出来的成绩。完整报告内容保留、警示含义不变；若某页本来就短，允许不减少。将长文移入折叠只计“降低默认密度”，不能记为“删除冗余”。

## 4. 第一批删改清单

原文来自当前源码/已查看的合成页面；部分只摘取一句。右侧是建议 UI 文案，实施时继续核对条件、实际字段与接口语义。用户尚未要求改计分和内容包，因此这里重点改展示层包装文字。

| 编号 / 位置 | 当前文字或结构 | 建议处理/文案 | 要保留的事实 |
|---|---|---|---|
| C01 · 首页 Hero | “每个人，都是一整个世界。”、“不止一种可能的你”、两句情绪描述与上下装饰标语 | 合并成标题“了解你的性格倾向”；副标题“十六型看偏好，大五看五个方面。” | 双测评定位；风格由设计承载 |
| C02 · 首页主按钮 | “找到适合我的测评” | “选择测评” | 仍滚动/聚焦到真实选择区，或进入目录 |
| C03 · 首页续答 | “继续上次的探索” | “继续上次测评” | 仅有真实草稿时出现 |
| C04 · 目录引导 | “不同的测评，照见不同的侧面。没有高低之分，只有更多理解。” | 删除；用两张卡片的实际差别替代 | 不把两种测评合并 |
| C05 · 十六型卡片 | 卡片名称下又解释“四维偏好”“获得参考类型，保留不确定性” | 核心描述“了解四个方面的偏好”；简短产出“参考类型与四维解读”择一呈现，避免重复 | 48 主测/最多 16 补充来自字段，结果保留不确定性 |
| C06 · 大五卡片 | “五个方面分别解读，没有类型和总分”并与摘要重复 | “了解五个方面的性格倾向”；必要时小字“各自解读，不给类型” | 不给类型、不求总分的业务规则不变，方法页完整说明 |
| C07 · 首页图鉴 | 多段关于人物、衣着、道具、职业和能力的免责声明 | 一句“插画是角色想象，不是测评结果。”；详细边界归到方法页 | 不伪装成测量或类型证据 |
| C08 · 首页宣言与路径 | “给自己一点余地”大区块 + “从好奇，到一点点理解”三步长说明 | 首批移除重复宣言；若保留流程，仅“选测评 → 作答 → 看报告” | 不删除选择与报告预览本身 |
| C09 · 登录 | “登录后才能把测评记录和报告放在服务器上，换设备也能接着看。答案与报告只属于你自己。” | “登录后可保存进度和报告。” | 不承诺未核实的绝对隐私；管理员已有授权查看能力不能被文案抹去 |
| C10 · 注册 | “注册后测评进度和报告会存在服务器上，换设备也能接着看。需要管理员提供的邀请码，不需要邮箱或手机号。” | “注册需要邀请码。”；字段旁“向管理员领取。” | 当前邀请码注册；无需再解释没有的字段 |
| C11 · 恢复码新建完成 | “账号建好了。这 8 个恢复码，请抄下来 —— 只显示这一次”及后续多段说理 | 标题“保存恢复码”；正文“仅显示一次，忘记密码时可用。每个码只能使用一次。” | 一次性展示/使用；实际数量由数据而非随意硬写 |
| C12 · 答题页标题 | “一屏一题，选完点「下一题」” | 用测评名称和“第 N / M 题”代替 | 控件本身给下一步 |
| C13 · 每题操作引导 | “下面两种做法，哪一种更像平时的你？按真实习惯选，不用选你觉得‘应该’做到的。” | 首次题前一句“选择更像平时自己的做法。”；后续不反复出现 | 不引导高低好坏，不改题干 |
| C14 · 中间档/说不好 | “两边差不多是指两种做法都像你、出现得差不多；说不好是现在无法判断，不是中间档。” | “中间档：两边差不多；说不好：暂时无法判断。” | 两者始终独立；可借清楚选项标签减少额外解释 |
| C15 · 已选状态 | “我说不好（已作答，不计分）”周围另有多段“处理过”的定义 | 选中控件显示“已选：说不好”；需要解释时一处“本题不计分” | UNKNOWN 与未答不同，由进度与校验准确表达 |
| C16 · 保存失败 | “有 N 题的作答还没写上去，刷新或离开会丢掉它们。” | “有 N 题未保存。” + “重试保存”；离开确认再说可能丢失的 N 题 | N 来自真实待同步数；未保存不标成已保存 |
| C17 · 十六型报告概览 | 大类型码、含类型码标题、类型中文名，随后再解释先看四句话 | 合并身份；摘要区标题“结果概览”，去掉“先看这四句话，就能了解这次结果”教学句 | 真实结论与状态；不得把略偏改成确定 |
| C18 · 略偏提示 | “有些方面只是略偏：你选择两端做法的差距不大。这些地方的两种描述都值得读，不必急着认定自己只属于一边。” | “部分维度差距较小，另一侧也值得参考。” | 仅 TENTATIVE 对应情形显示，维度标签保留 |
| C19 · 平分提示 | 多句关于为何没有四字母标题的说明 | “部分维度两侧得分相同，本次不指定唯一类型。” | TIED 不强出唯一类型，仍展示有效维度 |
| C20 · 报告候选 | 大段解释“不是概率、不是准确率、不是可能性，也不表示谁更准” | 数字旁“证据差异，非概率”；详细计算放“怎么算” | cost 不能变成匹配率；不能去掉所有语义解释 |
| C21 · 进阶阅读 | “进阶阅读：由类型推导的理论说明（不是额外测量）” | “类型推导 · 非额外测量” | basis 与限制仍随内容可达，平分不推导 |
| C22 · 分享区 | “复制的文字、导出的图片、图片的替代文本都来自同一份报告快照，说的永远是同一件事。” | 删除；仅留“复制摘要”“保存图片” | 同源由实现和测试保证，不让用户读实现承诺 |
| C23 · 历史报告 | “每一次提交都会留下一份当时的报告。规则以后若有更新，旧报告仍按当时那次解释，不会被重算。” | 标题“我的报告”；该长说明移到方法页 | 旧报告不重算的行为不变 |
| C24 · 恢复码管理 | “服务器只存了不可逆的校验值，谁也没法把它还原成你能抄下来的码……” | “重新生成后，旧恢复码全部失效。” | 新码替换旧码；必要身份确认保留 |
| C25 · 数据导出 | “JSON 文件包含……没有密码、恢复码、会话与内部记录——那些本来就不该离开服务器。” | “下载账号资料、作答、报告和 AI 记录（JSON）。” | 部分导出与错误须如实标记；导出范围按当前接口核对 |
| C26 · 账号删除说明 | “按单份报告删除的功能还没有做好……只能连账号一起注销” | **纠错**：“删除单份报告，请前往「我的报告」。” | 当前已有删除入口；不能诱导用户为删一份报告注销账号 |
| C27 · 注销 | “无法恢复，也不能撤销。导出数据是唯一能把它们带走的办法……” | “注销将删除账号及测评数据，无法恢复。” + “先导出数据” | 实际删除范围、确认密码、防重复；导出不完整时当场提示 |
| C28 · 页脚 | 多段作者说明、非官方说明、不可招聘诊断、即时预览/服务端计算解释 | 常规页收为“结果仅供自我探索参考” + “方法与隐私”；量表许可与署名按要求保留可达 | 旧流程署名不删；当前量表身份和边界能找到 |

C26 是源码可证的文字与功能不一致，本轮只给修正方案；未执行真实删除。C09 的“只属于你自己”也不宜继续作绝对承诺，因为 README 已说明管理员可查看成员报告；准确范围应由权限与隐私说明承载。

## 5. 错误、空态与状态的写法

统一使用“发生了什么 → 能做什么”，避免“为了保证您的……系统采用了……”式解释。

| 场景 | 建议文案 | 动作 |
|---|---|---|
| 目录载入失败 | 测评列表未能加载。 | 重试 |
| 草稿暂未确认 | 未能读取上次进度。 | 重试 |
| 没有报告 | 还没有报告。 | 选择测评 |
| 筛选后无报告 | 还没有大五报告。 | 查看全部 / 选择测评，择合适主次 |
| 保存失败 | 有 N 题未保存。 | 重试保存 |
| 需要重新登录 | 登录后继续保存。 | 重新登录 |
| 冲突 | 另一处的进度已更新。 | 查看并处理，沿用已有具体动作 |
| 离开有未保存数据 | 离开会丢失这 N 题尚未保存的改动。 | 留在此页 / 确认离开 |
| 报告暂不可用 | 报告暂时无法打开。 | 重试；按 401/403/404 原语义分流 |
| 大五单维信息不足 | 本项信息不足。 | 查看原因 |
| AI 关闭 | AI 解读暂未开放。 | 固定报告继续可读，不出现不可用生成按钮 |
| AI 失败且可重试 | 本次解读未完成。 | 重试，保持额度/重复请求约束 |
| AI 结果未知 | 还无法确认本次结果。 | 查询结果，不直接当作失败重发 |
| 导出不完整 | 本次导出不完整，缺少：{实际部分}。 | 重试导出 |

按钮不要写“我知道了”来代替实际动作，不把 403/404、身份失效和网络失败全部合并为“出了点问题”。

## 6. 必须当场保留的最短提示

精简不等于隐瞒，以下提示必须出现在相关操作/结论附近，但无需到处重复：

- 未保存与冲突：当前改动是否安全、下一步会不会丢改动。
- 注册/恢复：邀请码要求；恢复码只显示一次、重新生成使旧码失效。
- 不确定结果：略偏/平分/覆盖不足；信息不足不能暗示已有有效结论。
- 参考图示：候选 cost 非概率；理论推导非额外测量；大五不做总分/人群排名。
- AI 主动调用：发送什么数据、生成操作与额度、是否演示；失败不影响固定报告。
- 删除和注销：删除对象、不可恢复及当前导出不完整的事实。

不要求这些都出现在首页或每张卡片上。报告的通用边界可以统一成一条短说明；与特定维度有关的易误读内容在该处按需保留。

## 7. 不允许采用的“精简”办法

1. 删正文解释，却新增一堆 tooltip、问号图标、轮播引导，增加操作成本。
2. 只改成短句，仍把同一含义在标题、副标题、卡片、页脚重复四遍。
3. 截断固定报告、把“不确定”删成确定结论、用小字隐藏警示。
4. 大段改写题干、评分锚点或内容包而不处理版本与历史兼容。
5. 把整页文字变成英文装饰标签，或换一批同样空泛的“发现真正的你”。
6. 把“代码注释、开发文档需要解释清楚”误解成“用户页面也必须全讲”。
7. 为通过机械字符串测试保留过时文字；或反过来删除真正保护数据与语义的断言。

## 8. 给实施者的工作顺序

先列出当前可见文案及它在什么状态出现，标成“删 / 缩 / 按需 / 必留 / 纠错”。先处理 C26、C09 的事实问题，再按首页 → 登录 → 答题外围 → 报告外围 → 账号逐页推进。

每页先删冗余，再重排结构、调整间距，最后微调字号。避免先画一个更大更华丽的版式，然后为了填空重新加回文案。

提交交接记录时说明：删了什么、保留什么必要提示、哪些属于状态性内容、哪些涉及固定报告而保持不变。给实际改前/改后片段和字符统计，不用“更简洁、更高级”等主观话作为证据。
