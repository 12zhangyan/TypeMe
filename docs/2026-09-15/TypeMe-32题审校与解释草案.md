# TypeMe 32题审校与解释草案

日期：2026-09-15 · 配套：[产品方案](TypeMe-测评可信度调整-产品方案.md)、[开发方案](TypeMe-测评可信度调整-开发方案.md)。

**本文是内容审校与试用输入，不是已经验证有效的新量表。** 当前原题来自本项目 `backend/src/main/resources/content/questionnaire-quick.yml`，候选基于现有中文材料及原始量表含义提出；不复制竞品题库。

## 1. 使用说明

- 题号、维度和direction沿用原量表映射，详见开发方案；表内“左/右”永远对应数字1/5，不是维度字母顺序。
- 表中“保留”只表示本轮没有明确必要改动，不代表有效性已经验证。
- `L`：语言可理解性；`B`：两端未必互斥/对称；`C`：可能受情境、能力或社会评价影响。风险是内容分析判断，不是已得到统计验证的缺陷。
- `优先审校`的题必须先核对英文原义，并在认知访谈中复述验证；禁止开发者自行标为verified。可进入明确标识draft的本地试用包。
- 所有帮助文案与题面共同版本化；点开帮助不会改变评分，不在线调用AI临时解释。
- 每道题均提供“暂时无法判断”。两侧都不适用、没有经历、没理解时不要引导选3。

## 3. 每题帮助文字草案

统一放在“这题是什么意思？”内，不默认全部展开。以下以候选题面为背景；若题面审校回退，帮助必须同步审校。每条最后均可追加公共短句：`如果仍不能判断，或两边都不适用，可以选择“暂时无法判断”。`

| Q | 帮助文字候选 |
|---:|---|
| 1 | 比较你通常用什么方式记住要做的事。两种方式都会用时，按你觉得更接近自己的程度选择，不是评哪种方式更好。 |
| 2 | 比较一般情况下先保留疑问还是先愿意相信的倾向。不是要求你忽略证据、相信可疑信息，也不是评价诚实程度。 |
| 3 | 比较你对独处的通常感受。这里不要求你永远喜欢独处或永远不喜欢独处；若两侧差不多符合，可选中间。 |
| 4 | 比较对事情现有样子的感受。不是问是否努力、能否改变现状，也不是问你对某一件重大问题的态度。 |
| 5 | 回想通常对自己房间内物品的处理方式。不要只按一次大扫除后的样子回答；如果没有自己的空间，也可以暂时无法判断。 |
| 6 | 左侧问你是否把“像机器人”看作负面评价；右侧问你是否希望有机械式运作的思考方式。这是比喻，若觉得两侧不能表达你的看法，可以无法判断。 |
| 7 | 左侧描述精力活跃，右侧描述平和温和的状态。两种描述可能同时符合；不要仅凭今天疲劳与否判断，也不涉及健康评价。 |
| 8 | 选择题提供选项；论述题需要自己组织较完整的文字。比较愿意回答哪种，不是问哪种能拿高分；没有相关经历可暂不判断。 |
| 9 | 比较安排事情时呈现出的随性零散或条理感。不是评价勤劳、能力或是否守规矩。该解释的场景范围须与最终题面一致。 |
| 10 | 比较面对别人言语时通常的感受程度。不代表敏感就是弱点，也不要求你对伤害性的言语无动于衷。 |
| 11 | 比较共同做事与独立做事时的发挥感受。不是问是否喜欢同事，也不是问你有没有能力与别人合作。 |
| 12 | “当下”指眼前正在发生的事；“未来”指尚未发生的情况。比较注意力通常更偏向哪里，不是问会不会做计划。 |
| 13 | 比较开始规划的时间早晚。不是判断你会不会守约；不同事情差别很大、没有通常偏向时，可以暂不判断。 |
| 14 | “尊重”侧重敬重和认可；“喜欢”侧重亲近和好感。两者都想要很常见，按两侧符合程度选择。 |
| 15 | 回顾你通常参加聚会后的感受。不要只用一次特别愉快或特别累的聚会代表全部；疲惫与兴奋也可能同时出现。 |
| 16 | 比较自己通常更容易融入周围，还是更显得不同。不是判断哪一边更有个性或更优秀，也不是要求刻意迎合别人。 |
| 17 | 比较作选择时继续留着几个方案，还是选定并确定一个方案的倾向。这里不特指恋爱关系或重大人生承诺。 |
| 18 | 比较你希望擅长的事情：处理物品的问题，或帮助别人处理他们的问题。不是问现在会不会修理，也不把其中一边说成更有爱心。 |
| 19 | 比较交流中通常说与听的相对比例。不是判断谁更有价值，也不要求按一次会议或特定岗位职责回答。 |
| 20 | “经过”是发生了哪些事；“含义”是你认为这件事说明了什么。比较讲述时的侧重，不是在问哪个更真实。 |
| 21 | 比较拿到任务后通常多快开始并完成。不要把临时被其他事情阻挡直接当作拖延，也不因此评价你是否负责。 |
| 22 | 左侧侧重自己的感受，右侧侧重理性分析。两者都可能参与决定；不是“感性的人不理智”或“理性的人没有感受”。 |
| 23 | 比较通常更愿意待在家还是出门活动。出门不一定是社交，在家也可以与人互动；受出行条件限制时可以暂不判断。 |
| 24 | “整体”指事情的大体结构和全貌；“细节”指具体组成和小处。若采用“先”字版本，需明确比较了解顺序，而不是能力。 |
| 25 | “现场应对”是在情况出现后调整做法；“事先准备”是在之前做好安排。不是问能否在危险事件中随意行动。 |
| 26 | 一侧强调对不同人适用的公平原则，一侧强调对具体处境和感受的体谅。两者可能兼顾，不存在更高尚的标准答案。 |
| 27 | 比较大声喊话这件事对你是否自然。嗓音条件或场合限制使你难以回答时，可以无法判断；不是评价胆量。 |
| 28 | “理论解释”是用概念、原理说明事情；“事实和证据”是观察或实践中获得的信息。两者都有价值，不是空想与科学的对比。 |
| 29 | 比较工作投入与玩乐投入两种描述对你的符合程度。你可以两边都投入或都不投入；不是要求你必须把工作或娱乐放第一位。 |
| 30 | 一侧描述面对情绪的自在程度，另一侧描述重视情绪的程度。两者不是严格相反；若无法用这对描述定位，选择无法判断。 |
| 31 | 一侧关于在人前展示/表演，另一侧关于当众讲话。若自己对这两种场景感受明显不同，不必强行用一个分值概括。 |
| 32 | 一侧关心人物、事件、时间等信息，另一侧关心原因。两边都想了解是可能的，不代表哪个人更深入或更聪明。 |

## 4. 不能用润色掩盖的题项问题

- Q6：一端是对用语的评价，一端是对头脑的愿望；改得更顺仍可能不对称。
- Q8：考试形式偏好可能来自教育/写作经历，不能靠换成“生活中选择题”恢复同义。
- Q18：修物与助人的兴趣不一定等同于思考/情感决策偏好。
- Q27：喊话的自然程度可能有能力或规范因素，不直接等于内外向。
- Q29：工作投入与娱乐投入可同时很高；强迫二选一可能丢掉用户真实表达。
- Q30/Q31：两端涉及不同侧面的体验，解释可以承认这一点，不能虚构为完全对立。

上述题不能随意改成“更像MBTI”的新题后继续称原版OEJTS。若试用反复显示不适用，需要单独启动新量表/题项替换研究；在当前版本里给用户合法的无法判断出口，并限制报告。

## 5. 内容审校记录模板

每题维护记录：`sourceItemId / currentText / proposedText / proposedHelp / riskCodes / semanticChange / reviewerDecision / interviewEvidence / localeRevision`。

状态从 `draft` → `reviewed` → `field_checked`；“validated”不在开发者自动选项内，需对应研究报告。

- draft：本文候选，尚未由真人审校或试用。
- reviewed：有实际的中英文语义审校记录；不能只因单元测试通过改状态。
- field_checked：有对应版本的认知访谈证据，问题及处理可追溯；仍不代表信效度通过。
- rejection：候选与原题构念/极向偏离，回退当前已记录版本或重新提出候选；不得以去掉校验来通过构建。

**当前32题候选均为draft。** 工程可以完成内容结构、帮助交互和本地试用版本；后续上线状态据实际审校更新。本轮没有新增真人验证结论。
