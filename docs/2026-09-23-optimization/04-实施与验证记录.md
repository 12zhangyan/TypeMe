## 本轮文件与行为

- `AssessView.vue`：路由离页时先尝试保存，失败提供明确去留选择；刷新/关闭在未确认答案时触发浏览器原生提示，不保证关闭时异步保存完成。
- `BigFiveAssessView.vue`：普通子组件不再依赖无效的组件离页守卫；补弹窗键盘焦点管理与清理。
- `bigFiveV3.ts`、`AssessChooserView.vue`：同一次大五创建意图不换键、不并发；草稿失败不当空列表，未取得可信结果时不能自动创建。
- `PlatformController.java`、`PlatformQueryService.java`、`platformV3.ts`：开放草稿及报告种类的可选服务端过滤，未传参数的旧接口行为保留。
- `ReportsListView.vue`：服务端分页及筛选，区分全部总数与本页数量，处理乱序响应与删除末页，筛选空态准确表述。
- `style.css`：修复 200% CSS 缩放时页脚品牌字溢出。
- `AttemptRouterView.vue`、中性元信息 API 与 H2/组件测试：正常按已确认归属的量表种类分流，避免拿大五接口的 409 当路径选择；不返回答案或题面。
- `localTime.ts` 及草稿/列表/报告/比较页面：统一按用户本地时区显示；`BigFiveScoringPolicy.java` 移除未使用且量程错误的旧方法。
- `AttemptCreationWriter.java`、两类创建服务及 `IdempotencyGuard.java`：修复自调用事务无效与标记失败导致重复创建的窗口；只清已完成过期键，旧未完成键不盲目重建。`AttemptCreationTransactionIT` 在隔离 H2 注入标记故障并测试旧记录。
- `bigFiveV3.ts`：旧加载和创建响应在切草稿/重置后不能接管新状态；`aiAnalysisV3.ts`：隐藏页不请求、失败退避、限流处理。
- `05-内容发布与研究准备.md`：当前事实、内容源边界、审校字段、发布与研究模板；没有改动题目或已绑定包。
- 新增/更新相关组件、store 与 H2 测试；没有修改题目、计分、内容包或历史报告快照。
